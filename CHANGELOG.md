# Changelog

## [Unreleased]

### Added

- Renamed the engine to `recording_studio_users` / `RecordingStudioUsers`.
- Added UUID user roots and immutable, append-only profile snapshots.
- Added explicit provisioning and Recording Studio profile revision services.
- Added fail-closed policy, lookup, presentation, loader, and current-profile search contracts.
- Added conservative install and migration generators.
- Added optional public-API-only RecordingStudioAdmin resource registration.

### Removed

- Removed generic template hooks, example services, browser routes, generated coverage output, and template documents.
